Перед началом

  • Нужен Python 3.12 или новее. При установке отметьте «Add Python to PATH».
  • Работаем в PyCharm Community. Один файл на одно задание: task1.py, task2.py и так далее.
  • Запуск из терминала: python task1.py. В PyCharm: зелёная кнопка или Shift+F10.
  • Окружение для проекта создаётся командой python -m venv venv.

Сначала решаете сами. Потом открываете подсказку, и только после неё решение. Если ваш код отличается от решения, но работает, это нормально.

Задание 2

Калькулятор

Программа спрашивает два числа и операцию (+, -, *, /) и печатает результат. Сначала напишите простую версию. Затем сделайте так, чтобы она не падала при вводе «abc» и при делении на ноль.

Подсказка

Ввод «abc» вызывает исключение ValueError, его ловят через try / except. Деление на ноль проще проверить условием заранее. Чтобы не повторять код, вынесите чтение числа в функцию.

Решение: простая версия 
a = float(input("Первое число: "))
op = input("Операция (+, -, *, /): ")
b = float(input("Второе число: "))

if op == "+":
    print(a + b)
elif op == "-":
    print(a - b)
elif op == "*":
    print(a * b)
elif op == "/":
    print(a / b)
else:
    print("Неизвестная операция")
Решение: с проверками 
def read_number(prompt):
    while True:
        try:
            return float(input(prompt))
        except ValueError:
            print("Нужно ввести число.")


a = read_number("Первое число: ")
op = input("Операция (+, -, *, /): ")
b = read_number("Второе число: ")

result = None
if op == "+":
    result = a + b
elif op == "-":
    result = a - b
elif op == "*":
    result = a * b
elif op == "/":
    if b == 0:
        print("На ноль делить нельзя.")
    else:
        result = a / b
else:
    print("Неизвестная операция")

if result is not None:
    print(f"{a} {op} {b} = {result}")
Задание 3

Круг

Запросите радиус, посчитайте площадь и длину окружности с помощью math.pi. Выведите оба числа с двумя знаками после запятой. Радиус должен быть положительным.

Подсказка

Формат с двумя знаками: f"{x:.2f}". Проверку радиуса удобно делать в цикле while True, который завершается через break.

Решение 
import math

while True:
    try:
        r = float(input("Радиус: "))
    except ValueError:
        print("Нужно ввести число.")
        continue
    if r <= 0:
        print("Радиус должен быть больше нуля.")
        continue
    break

print(f"Площадь: {math.pi * r ** 2:.2f}")
print(f"Длина окружности: {2 * math.pi * r:.2f}")
Задание 4

Числа Армстронга

Трёхзначное число называют числом Армстронга, если оно равно сумме кубов своих цифр: 153 = 1³ + 5³ + 3³. Найдите все такие числа от 100 до 999.

Усложнение: обобщите программу на числа любой длины, где степень равна количеству цифр. Чем такое определение отличается от исходного?

Подсказка

Цифры можно получить через // 100, // 10 % 10 и % 10. Или превратить число в строку и пройтись по её символам.

Решение: трёхзначные 
for n in range(100, 1000):
    a, b, c = n // 100, n // 10 % 10, n % 10
    if a ** 3 + b ** 3 + c ** 3 == n:
        print(n)
Решение: любая длина 
def is_armstrong(n):
    digits = str(n)
    power = len(digits)
    return sum(int(d) ** power for d in digits) == n


start = int(input("От: "))
end = int(input("До: "))
print([n for n in range(start, end + 1) if is_armstrong(n)])
