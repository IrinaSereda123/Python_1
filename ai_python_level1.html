Перед началом

В этих работах вы подключитесь к OpenRouter — агрегатору, который даёт единый API сразу к нескольким десяткам моделей (Llama, Mistral, Gemma и др.). Научитесь отправлять запросы, добавлять контекст и собирать полноценного AI-помощника на Python.

Подготовка. Зарегистрируйтесь на openrouter.ai → Keys → Create Key. Скопируйте ключ (начинается с sk-or-). Установите библиотеки:

pip install requests python-dotenv aiohttp aiogram

Ключ храните в файле .env рядом со скриптом:

OPENROUTER_API_KEY=sk-or-v1-ваш_ключ_здесь

Если работаете в PyCharm — установите плагин EnvFile или загружайте .env через python-dotenv, как показано в коде ниже.

Работа 1

Консольный AI-помощник

Цель: отправить первый запрос к модели через OpenRouter, использовать системный промпт и обработать ответ.

Базовый код — assistant.py

import os
import requests
from dotenv import load_dotenv

load_dotenv()
API_KEY = os.getenv("OPENROUTER_API_KEY")
URL = "https://openrouter.ai/api/v1/chat/completions"

def ask_llm(prompt, system_prompt=None):
    headers = {
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    }
    messages = []
    if system_prompt:
        messages.append({"role": "system", "content": system_prompt})
    messages.append({"role": "user", "content": prompt})
    payload = {
        "model": "meta-llama/llama-3.3-70b-instruct",
        "messages": messages,
        "temperature": 0.7,
        "max_tokens": 200,
    }
    response = requests.post(URL, json=payload, headers=headers)
    response.raise_for_status()
    return response.json()["choices"][0]["message"]["content"]

if __name__ == "__main__":
    print("AI-помощник (напишите 'выход' для завершения)")
    system = "Ты дружелюбный эксперт по программированию на Python. Отвечай кратко и понятно."
    while True:
        user_input = input("\nВы: ")
        if user_input.lower() in ("выход", "exit"):
            break
        answer = ask_llm(user_input, system)
        print(f"AI: {answer}")

Задание 1.3 (★): полноценный скрипт 
import os, requests
from dotenv import load_dotenv
load_dotenv()
API_KEY = os.getenv("OPENROUTER_API_KEY")
URL = "https://openrouter.ai/api/v1/chat/completions"

SYSTEM = "Ты дружелюбный эксперт по Python. Отвечай кратко."
history = []
temperature = 0.7

def ask_llm(messages):
    headers = {"Authorization": f"Bearer {API_KEY}", "Content-Type": "application/json"}
    payload = {"model": "meta-llama/llama-3.3-70b-instruct",
               "messages": messages, "temperature": temperature}
    resp = requests.post(URL, json=payload, headers=headers)
    resp.raise_for_status()
    return resp.json()["choices"][0]["message"]["content"]

print("AI-помощник. Команды: /history, /clear, /temp [число], /exit")
while True:
    user = input("\nВы: ")
    if user.lower() in ("/exit", "выход"):
        break
    if user == "/history":
        for m in history[-10:]:
            print(f"{m['role']}: {m['content'][:100]}")
        continue
    if user == "/clear":
        history = []
        print("История очищена.")
        continue
    if user.startswith("/temp"):
        try:
            temperature = float(user.split()[1])
            print(f"Температура: {temperature}")
        except (IndexError, ValueError):
            print("Используйте: /temp 0.7")
        continue
    history.append({"role": "user", "content": user})
    messages = [{"role": "system", "content": SYSTEM}] + history[-10:]
    answer = ask_llm(messages)
    print(f"AI: {answer}")
    history.append({"role": "assistant", "content": answer})

AI с реальными данными о погоде

Цель: объединить вызов открытого API погоды с запросом к LLM — модель будет давать советы по одежде, опираясь на реальные данные.

Вариант 1: только погода, без ИИ

import requests

while True:
    city = input("\nВведите город (на английском, 'выход' для завершения): ").strip()
    if city.lower() in ("выход", "exit"):
        break

    geo_url = f"https://geocoding-api.open-meteo.com/v1/search?name={city}&count=1&format=json"

    wind = weather_resp["current_weather"]["windspeed"]

Вариант 2: погода + советы от LLM

import os
import requests
from dotenv import load_dotenv

load_dotenv()
API_KEY = os.getenv("OPENROUTER_API_KEY")
URL = "https://openrouter.ai/api/v1/chat/completions"

def get_weather(city):
    geo_url = f"https://geocoding-api.open-meteo.com/v1/search?name={city}&count=1&format=json"
    geo_resp = requests.get(geo_url).json()
    if not geo_resp.get("results"):
        return None, None
    lat = geo_resp["results"][0]["latitude"]
    lon = geo_resp["results"][0]["longitude"]
    weather_url = f"https://api.open-meteo.com/v1/forecast?latitude={lat}&longitude={lon}&current_weather=true"
    w = requests.get(weather_url).json()
    return w["current_weather"]["temperature"], w["current_weather"]["windspeed"]

def ask_llm(prompt):
    headers = {"Authorization": f"Bearer {API_KEY}", "Content-Type": "application/json"}
    payload = {
        "model": "meta-llama/llama-3.3-70b-instruct",
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
        "max_tokens": 200,
    }
    resp = requests.post(URL, json=payload, headers=headers)
    resp.raise_for_status()
    return resp.json()["choices"][0]["message"]["content"]

while True:
    city = input("\nВведите город на английском (или 'выход'): ").strip()
    if city.lower() in ("выход", "exit"):
        break
    temp, wind = get_weather(city)
    if temp is None:
        print("Город не найден, попробуйте ещё раз.")
        continue
    print(f"\nПогода в {city}: {temp}°C, ветер {wind} км/ч")
    prompt = (
        f"Погода: температура {temp}°C, ветер {wind} км/ч. "
        "Дай краткий совет (2–3 предложения): как одеваться, нужен ли зонт, "
        "стоит ли выходить на улицу. Ответь дружелюбно, без лишних слов."
    )
    advice = ask_llm(prompt)
    print(f"Совет от ИИ: {advice}")
Распознавание городов на кириллице 
city_map = {
    "минск": "Minsk", "москва": "Moscow", "киев": "Kyiv",
    "питер": "Saint Petersburg", "брест": "Brest", "гродно": "Grodno",
}
def extract_city(text):
    text_lower = text.lower()
    for ru, en in city_map.items():
        if ru in text_lower:
            return en
    return text.split()[-1].strip(",.?!")

Работа 3

Telegram-бот на aiogram + LLM + курс валют НБРБ

Цель: собрать асинхронного Telegram-бота на aiogram, подключить OpenRouter для умных ответов, добавить историю диалога и запрос курса валют через API Национального банка Беларуси с поддержкой даты и разных валют (USD, EUR, RUB).

Почему aiogram? Асинхронный фреймворк, высокая производительность, поддержка FSM и роутеров. Стандарт для современных ботов на Python. Документация: docs.aiogram.dev.

Шаг 1: эхо-бот (проверка токена)

import os
from dotenv import load_dotenv
from aiogram import Bot, Dispatcher, types
from aiogram.filters import Command
import asyncio

load_dotenv()
TELEGRAM_TOKEN = os.getenv("TELEGRAM_TOKEN")

bot = Bot(token=TELEGRAM_TOKEN)
dp = Dispatcher()

@dp.message(Command("start"))
async def cmd_start(message: types.Message):
    await message.answer("Привет! Я эхо-бот. Просто напиши что-нибудь.")

@dp.message()
async def echo(message: types.Message):
    await message.answer(f"Эхо: {message.text}")

async def main():
    print("Эхо-бот запущен")
    await dp.start_polling(bot)

if __name__ == "__main__":
    asyncio.run(main())

import os, aiohttp
from dotenv import load_dotenv
from aiogram import Bot, Dispatcher, types
from aiogram.filters import Command
import asyncio

load_dotenv()
API_KEY = os.getenv("OPENROUTER_API_KEY")
TELEGRAM_TOKEN = os.getenv("TELEGRAM_TOKEN")
URL = "https://openrouter.ai/api/v1/chat/completions"

bot = Bot(token=TELEGRAM_TOKEN)
dp = Dispatcher()

async def ask_llm(prompt):
    headers = {"Authorization": f"Bearer {API_KEY}", "Content-Type": "application/json"}
    payload = {
        "model": "meta-llama/llama-3.3-70b-instruct",
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.7,
        "max_tokens": 200,
    }
    async with aiohttp.ClientSession() as session:
        async with session.post(URL, json=payload, headers=headers) as resp:
            data = await resp.json()
            return data["choices"][0]["message"]["content"]

@dp.message(Command("start"))
async def cmd_start(message: types.Message):
    await message.answer("Я AI-бот на OpenRouter. Задавай любые вопросы!")

@dp.message()
async def handle_message(message: types.Message):
    answer = await ask_llm(message.text)
    await message.answer(answer)

async def main():
    print("AI-бот запущен")
    await dp.start_polling(bot)

if __name__ == "__main__":
    asyncio.run(main())

Полный интеграционный пример (всё вместе) 
import os, aiohttp, re
from datetime import datetime
from dotenv import load_dotenv
from aiogram import Bot, Dispatcher, types
from aiogram.filters import Command
import asyncio

load_dotenv()
API_KEY = os.getenv("OPENROUTER_API_KEY")
TELEGRAM_TOKEN = os.getenv("TELEGRAM_TOKEN")
URL = "https://openrouter.ai/api/v1/chat/completions"

bot = Bot(token=TELEGRAM_TOKEN)
dp = Dispatcher()
user_sessions = {}
SYSTEM_PROMPT = "Ты дружелюбный помощник. Отвечай кратко."

async def ask_llm_with_history(user_id, text):
    if user_id not in user_sessions:
        user_sessions[user_id] = [{"role": "system", "content": SYSTEM_PROMPT}]
    user_sessions[user_id].append({"role": "user", "content": text})
    if len(user_sessions[user_id]) > 12:
        user_sessions[user_id] = [user_sessions[user_id][0]] + user_sessions[user_id][-10:]
    headers = {"Authorization": f"Bearer {API_KEY}", "Content-Type": "application/json"}
    payload = {"model": "meta-llama/llama-3.3-70b-instruct",
                "messages": user_sessions[user_id], "temperature": 0.8}
    async with aiohttp.ClientSession() as session:
        async with session.post(URL, json=payload, headers=headers) as resp:
            data = await resp.json()
            answer = data["choices"][0]["message"]["content"]
    user_sessions[user_id].append({"role": "assistant", "content": answer})
    return answer

async def get_rate(currency_code, date_str=None):
    if date_str is None:
        date_str = datetime.now().strftime("%Y-%m-%d")
    url = f"https://api.nbrb.by/exrates/rates/{currency_code}?parammode=2&ondate={date_str}"
    async with aiohttp.ClientSession() as session:
        async with session.get(url) as resp:
            if resp.status != 200:
                return None
            data = await resp.json()
            return {
                "rate": data["Cur_OfficialRate"],
                "scale": data["Cur_Scale"],
                "name": data["Cur_Name"],
                "date": data["Date"],
            }

@dp.message(Command("start"))
async def cmd_start(message: types.Message):
    await message.answer(
        "Бот с OpenRouter и курсом валют НБРБ.\n"
        "/clear — очистить историю.\n"
        "Примеры: «курс доллара», «курс евро на 2024-05-13»"
    )

@dp.message(Command("clear"))
async def cmd_clear(message: types.Message):
    user_sessions.pop(message.from_user.id, None)
    await message.answer("История очищена.")

@dp.message()
async def handle_message(message: types.Message):
    text = message.text.lower()
    user_id = message.from_user.id
    if "курс" in text:
        currency = None
        if "доллар" in text or "usd" in text:
            currency = "USD"
        elif "евро" in text or "eur" in text:
            currency = "EUR"
        elif "рубл" in text or "rub" in text:
            currency = "RUB"
        else:
            await message.answer("Напишите «курс доллара», «курс евро» или «курс рубля».\nМожно указать дату: «курс доллара на 2024-05-13»")
            return
        date_match = re.search(r'(\d{4}-\d{2}-\d{2})', text)
        date_str = date_match.group(1) if date_match else None
        rate_data = await get_rate(currency, date_str)
        if rate_data is None:
            await message.answer(f"Не удалось получить курс {currency} на указанную дату. Проверьте дату.")
            return
        scale = rate_data["scale"]
        rate = rate_data["rate"]
        name = rate_data["name"]
        date_display = rate_data["date"][:10]
        if scale == 1:
            await message.answer(f"Курс {name} на {date_display}: {rate} руб.")
        else:
            await message.answer(f"Курс {scale} {name} на {date_display}: {rate} руб. (за {scale} единиц)")
    else:
        answer = await ask_llm_with_history(user_id, message.text)
        await message.answer(answer)

async def main():
    print("Бот запущен")
    await dp.start_polling(bot)

if __name__ == "__main__":
    asyncio.run(main())
Самостоятельные задания

Что сделать самостоятельно

Задания расположены по возрастанию сложности. Звёздочка ★ — повышенная.

Задание 1. Сменить модель на Llama 4 Scout

В OpenRouter доступны новые модели семейства Llama 4. Изучите список моделей и замените модель в запросах с meta-llama/llama-3.3-70b-instruct на meta-llama/llama-4-scout-17b-16e-instruct (или другое актуальное название). Сравните качество ответов, скорость работы и потребление токенов. Подсказка: параметр model в payload.

Задание 2. Исследовать другие модели

OpenRouter даёт доступ не только к Llama, но и к Mixtral, Gemma, Qwen и десяткам других. Найдите на странице моделей альтернативы (например, mistralai/mixtral-8x7b-instruct, google/gemma-2-9b-it). Измените код любого задания, чтобы использовать другую модель, и сравните ответы.

Задание 3 (★). Улучшить Telegram-бота

Добавьте в бота из работы 3 одно или несколько улучшений:

  • Инлайн-кнопки — для быстрого выбора валюты (USD, EUR, RUB) или очистки истории. Используйте InlineKeyboardMarkup и InlineKeyboardButton.
  • Команда /menu — список доступных возможностей (курс валют, очистка истории, помощь).
  • Кэширование курсов — храните курс в переменной с меткой времени и обновляйте раз в несколько часов, чтобы не запрашивать API НБРБ при каждом сообщении.
  • Дата в свободном формате — например, «курс доллара на вчера».
  • Логирование — запись запросов в файл через модуль logging.

Реализуйте хотя бы одно улучшение и продемонстрируйте результат.
